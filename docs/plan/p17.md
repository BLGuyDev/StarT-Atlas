# UHV: Abydos metals and runic circuits

<!-- Generated from the front matter by tools/refresh_body.js. Edit the front matter, not this text. -->

**Phase id:** `p17` · **Era:** [UHV · Ancient Gate](../eras/uhv.md)

Zapolgium, the UHV superconductors, runic circuits, the UHV machine parts, the runic mainframe (UEV circuit) with UEPIC chips, then the UHV controllers and the Ancient Stargate.
